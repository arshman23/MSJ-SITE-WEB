MSJ GROUP — SITE INTERNET
========================

L'accueil du groupe est index.html.
Chaque univers a sa propre page : expert.html, assurance.html,
gestion.html et domiciliation.html.
MSJ GESTION propose un secrétariat externalisé sur devis.
La nouvelle affiche Expert est proposée en JPG et PDF.

Conservez tous les fichiers HTML et le dossier assets ensemble.
Aucune installation de dépendance ni compilation n'est nécessaire.
Pour le développement : python3 -m http.server 8000 --bind 127.0.0.1

CONTACT
contact.html prépare un e-mail pour cabinet@msjexpert.fr.
Le visiteur doit l'envoyer depuis sa propre messagerie.
Il peut aussi copier ou télécharger le message préparé.
Aucun message n'est envoyé automatiquement par le site.

MISE EN LIGNE
GitHub Pages : branche main, dossier / (root).
Les mises à jour de main déclenchent une nouvelle publication.

PERSONNALISATION
Textes : fichiers .html de chaque page.
Style : assets/site.css.
Interactions : assets/site.js et assets/contact.js.
Provenance des visuels : assets/CREDITS.txt.
Instructions complètes : README.md.

Les coordonnées proviennent de la base fournie. Les informations
légales et professionnelles restant à compléter sont précisées
dans informations.html. Les visuels d'ambiance sont illustratifs.
